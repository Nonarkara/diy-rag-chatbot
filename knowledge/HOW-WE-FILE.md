# How we file — มาตรฐานที่ชุดนี้คัดลอกมาจาก Smart City Thailand

โฟลเดอร์ `knowledge/` คือสมอง บอทตอบได้เฉพาะสิ่งที่อยู่ในนี้

ของจริงที่วิ่งอยู่ที่ rag.nonarkara.org แยกสองชั้น: `RAW/` (ต้นฉบับ) กับ `WIKI/{หมวด}/*.md` (หน้าที่กลั่นแล้ว) ชุดสอนนี้ยุบเป็น `knowledge/` ให้คนทั่วไปโยนไฟล์ได้ แต่ **หน้าที่ให้บอทพูด** ควรเป็นมาร์กดาวน์ที่จัดหมวดแบบด้านล่าง ไม่ใช่ซุปเมนูเว็บ

## หน้าหนึ่งหน้า ดึงแล้วอ่านได้

```md
---
title: "ชื่อสั้นที่คนอ่านรู้เรื่อง"
category: faq
source: "https://example.go.th/page หรือ ชื่อไฟล์.pdf"
---

# ชื่อสั้นที่คนอ่านรู้เรื่อง

ถาม: …คำถามที่คนจริงถาม…
Q: …the same question in English…
A: …คำตอบ และขั้นต่อไปที่ระบุชื่อคนหรือหน่วยงาน…
```

- H1 มีครั้งเดียว ห้ามซ้ำกับบรรทัดถัดไป
- ถาม: กับ Q: ต้องชี้คำถามเดียวกัน เพื่อให้ไทยหรืออังกฤษดึงชิ้นเดียวกัน
- อย่าวางเมนูเว็บ คุกกี้แบนเนอร์ ฟุตเตอร์ หรือหัวข้อกลาง ๆ อย่าง 「Digital service View」
- ถ้าดึงเว็บแล้วเหลือแต่ลิงก์นำทาง — ทิ้ง แล้วเขียนสามประโยคที่ชี้ URL ต้นทาง

## หมวด

ชื่อโฟลเดอร์ภาษาอังกฤษตัวเล็ก `a-z0-9-` ไม่เกิน 32 ตัว

| โฟลเดอร์ | ใส่อะไร |
|---|---|
| `faq/` | คำถามหนึ่งข้อ คำตอบหนึ่งข้อ และบอกว่าถามใครแทนถ้าเกินขอบ |
| `briefings/` | กรอบที่หน่วยงานเขียนเอง ไม่ใช่หน้าเว็บที่ดึงมา |
| `policies/` | กฎ เกณฑ์ อันดับ ที่เผยแพร่แล้ว |
| `program/` | วิธีสมัคร ตราสัญลักษณ์ เครื่องมือ |
| `institutional/` | โครงสร้างหน่วยงาน รายชื่อที่เผยแพร่ ช่องทางติดต่อ |
| `general/` | สิ่งที่เหลือ |

เลือกหมวดจาก **สิ่งที่หน้านี้เป็น** ไม่ใช่จากโดเมนที่ดึงมา

## ทางเข้าของข้อมูลใหม่

1. วางต้นฉบับใน `knowledge/` (PDF / Word / ข้อความ / มาร์กดาวน์)
2. ถ้าเป็นหน้าเว็บ — ตัดเมนูออก เหลือเนื้อ เก็บ URL ใน `source`
3. จัดหมวด ตั้งชื่อไฟล์ให้อ่านรู้เรื่อง
4. ระบบอ่านเฉพาะไฟล์ที่แฮชเปลี่ยน ไม่ต้องสร้างดัชนีทั้งคลังใหม่
5. แก้ไฟล์ด้วยมือแล้ว รอให้ตัวเฝ้าโฟลเดอร์อ่านใหม่ก่อนคาดว่าบอทจะรู้

การปฏิเสธที่อยู่ในไฟล์ `faq/` ดึงได้ การปฏิเสธที่อยู่ในพรอมต์ระบบอย่างเดียว หายเมื่อเปลี่ยนโมเดล

ดูตัวอย่างใน `knowledge/faq/` และ `knowledge/briefings/`
